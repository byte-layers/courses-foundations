# courses-foundations

Les contenus de base de byte_layers, pour qui débute : ce qu'est un ordinateur, ce que font ses programmes et comment ils se répartissent entre les machines. Un dossier par contenu, à plat, chacun avec son `.layers/`.

| Dossier | Contenu | Type |
|---|---|---|
| `computer-layers/` | L'ordinateur en couches, du matériel au premier script | bit |
| `program-architectures/` | Les architectures d'un programme, du poste seul au n tiers | bit |

Chaque contenu s'appuie sur des schémas animés (blocs ` ```scene `, fichiers `assets/*.scene.json` au format `bl-scenes/0.2`) et demande l'extension 0.5.0 ou plus. Chaque contenu a son tag, de la forme `<dossier>/vN`.

Prérequis : aucun pour `computer-layers` ; `program-architectures` suppose `computer-layers`. Si vous essayez les commandes, les fichiers vont dans `~/byte-layers/`.
